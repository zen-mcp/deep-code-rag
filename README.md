# Create virtual environment (recommend)
```bash
python3 -m venv venv
source venv/bin/activate
```

# Install Tree-sitter and bindings
```bash
pip install tree-sitter tree-sitter-typescript tree-sitter-html
```

# Cài đặt Qdrant client và các thư viện khác
```bash
pip install qdrant-client python-dotenv sentence-transformers torch
```
